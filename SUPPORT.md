# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to do something, share what you built, or float an idea | [GitHub Discussions](https://github.com/dxmt/dxmt/discussions) |
| Report a bug | [A bug report](https://github.com/dxmt/dxmt/issues/new?template=bug_report.yml) |
| Ask for a feature | [A feature request](https://github.com/dxmt/dxmt/issues/new?template=feature_request.yml) |
| Ask for an integration with a framework or platform | [An integration request](https://github.com/dxmt/dxmt/issues/new?template=integration_request.yml) |
| Report a vulnerability | Privately, through [a security advisory](https://github.com/dxmt/dxmt/security/advisories/new) -- never in a public issue ([SECURITY.md](SECURITY.md)) |

Before asking whether something works, read `vectordb/docs/SUPPORT_MATRIX.md`: it says which
parts of the server are supported, which are experimental, and what each client covers.

Only the latest release and `main` are supported. Response targets are in
[MAINTAINERS.md](MAINTAINERS.md#what-to-expect).
