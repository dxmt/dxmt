## 发现并修复的问题

### 问题 1: MMR搜索类型错误

**问题:**
```python
TypeError: unsupported operand type(s) for *: 'float' and 'NoneType'
```

**根本原因:**
DXMT搜索结果默认不包含向量，导致向量操作中出现None值。

**解决方案:**
```python
# 过滤掉没有向量的候选项
valid_candidates = []
candidate_vectors = []
for candidate in candidates:
    if 'vector' in candidate and candidate['vector'] is not None:
        valid_candidates.append(candidate)
        candidate_vectors.append(candidate['vector'])
```

**状态:** ✅ 已修复

---

### 问题 2: DataLoader维度不匹配

**问题:**
```
维度不匹配: 期望 128，实际 384
```

**根本原因:**
当未指定嵌入模型时，DataLoader默认使用384维（MiniLM默认值），但测试创建的是128维表格。

**解决方案:**
添加 `embedding_dimension` 参数:
```python
def __init__(
    self,
    client: Client,
    table_name: str,
    embedding_model: Optional[str] = "all-MiniLM-L6-v2",
    batch_size: int = 100,
    embedding_dimension: Optional[int] = None  # 新增
):
    ...
    self.dimension = embedding_dimension or 384
```

**状态:** ✅ 已修复

---

### 问题 3: RAG应用OpenAI初始化

**问题:**
```
OpenAIError: 必须设置 api_key
```

**根本原因:**
RAGApplication初始化需要OPENAI_API_KEY环境变量。

**解决方案:**

