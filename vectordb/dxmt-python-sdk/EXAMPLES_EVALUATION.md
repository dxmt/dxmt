### 🐛 发现的问题

#### 问题 1: 混合搜索分数异常

**Alpha = 0.0 (纯文本搜索):**
```
1. ID: art1, Score: 1.0000  ← 正常
2. ID: art2, Score: 0.0000  ← ⚠️ 异常：应该有文本分数
3. ID: art3, Score: 0.0000  ← ⚠️ 异常：应该有文本分数
```

**期望：** 如果是纯文本搜索 (alpha=0.0)，所有结果都应该有基于 BM25 的文本相似度分数。

**实际：** 只有第一个结果有分数，其他都是 0.0000

**可能原因：**
- BM25 算法只返回了最相关的1个结果
- 或者混合搜索的分数归一化有问题
- 或者文本索引没有正确建立

#### 问题 2: 向量搜索全返回 1.0

**Alpha = 1.0 (纯向量搜索):**
```
1. ID: art3, Score: 1.0000
2. ID: art4, Score: 1.0000
3. ID: art2, Score: 1.0000
```

**异常：** 3个完全不同的文章向量相似度都是 1.0000（完美匹配）

**可能原因：**
1. 测试数据使用了相同的 embedding
2. 或者 embedding 维度太小（测试用的随机向量）
3. 或者余弦距离计算有问题

#### 问题 3: 全文搜索分数奇怪

**查询: 'neural networks'**
```
1. ID: art2, Score: 2.3766  ← ⚠️ BM25分数超过1.0？
```

**观察：** BM25 分数通常在 0-10 范围，但用户可能期望归一化到 0-1
